# Revised Architecture C pressure source

## Selected bounded revision

**Arrangement B — multiple independent water-triggered commercial branches** is selected for owner-requirement closure:

`5–7 × [HR V95000 Hydro 1F (1/2-20) + Leland 86202Z 38 g + required holder]`

`→ individual HP checks → HP collection bus → pressure regulator → fixed restriction → buoy-adjacent differential relief → buoy`

Each branch is independently replaceable, passive, non-electrical, non-pyrotechnic and water authorized. The exact `V95000-86202Z` pairing is **PUBLISHED CONFIGURATION SUPPORTED**. Five to seven is a sizing range, not a frozen count.

## Why count is not frozen

The maximum deployment depth, minimum temperature, inflation time, usable volume at depth, recovery load, buoy differential MAWP and environmental profile remain open. If the mission exceeds seven supported 38 g branches, the project must either obtain written approval for Arrangement C using fewer 60–150 g supplemental sources or revise the concept. More than seven small automatic branches is not selected because packaging, reset burden, leak points and synchronization qualification become disproportionate.

## Pressure boundary

The previous 2,500 psig value is not a final design pressure. The rule is:

`maximum credible cartridge pressure at maximum specified environment < temperature-derated allowable working pressure of every HP item with the required engineering/code margin`

`≥3,000 psig` remains a screening floor only. Leland must supply pressure-temperature data, and each puncture head, check, tube, fitting, bus and regulator inlet must have a controlled allowable/derating. Any item without this evidence is excluded from final selection.

## Low-pressure protection

The buoy is never exposed directly to cartridge equilibrium pressure. A qualified regulator provides pressure separation; a fixed restriction bounds transient/fault flow; a buoy-adjacent, preferably resettable differential relief protects the soft buoy. No relief number is selected until buoy operating differential and MAWP are verified. A buoy-integral relief may contribute only if its set/reseat/flow/depth qualification is documented.

## Field reset

Normal successful deployment is field-resettable: isolate and verify zero pressure; remove expended cylinders; inspect pins/seats/holders/checks; replace each cylinder, `V80040` and mandatory seals/pins/clips; dry and repack buoy; inspect pressure path; reset mechanism; perform qualified low-energy leak/function checks; restore transport-safe configuration. No routine pressure-vessel fabrication or depot rebuild is introduced. Exact rearm work instructions and installation torques/engagement remain supplier-controlled RFQ deliverables.

## Count-reduction off-ramp

Arrangement C may supersede Arrangement B only after the inflator/piercer manufacturer approves the exact larger cartridge, holder, puncture geometry, reaction load, sealing, flow and temperature envelope. Until then it is development direction, not accepted hardware.
