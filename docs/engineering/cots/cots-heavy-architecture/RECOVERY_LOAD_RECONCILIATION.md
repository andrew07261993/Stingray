# Recovery-load reconciliation

## Owner-controlled value

Preserve **500 lbf (2,224.111 N) as the owner-confirmed proof-level recovery requirement**.

## Repository evidence

The authoritative WP02 structural screen includes a 500 lbf total external-load row, provisionally divided across three arms. It reports 453.619 MPa nominal root stress against an assumed 1,170 MPa 17-4PH H900 yield and a 2.579 screening ratio. The same file explicitly classifies every row **DEVELOPMENT SCREEN; NOT APPROVED LOAD BASIS OR FEA**. Its calculation report says approved mission loads, nonlinear contact FEA, fatigue, proof and ultimate tests remain external.

The R2 source separately specifies 4.45 kN proof for finished recovery tether and individual harness legs and a 1,400 lbf manufacturer minimum strength for the raw 7/64-in AmSteel-Blue line. These component/process values do not establish a complete-system design or ultimate requirement.

## Disposition

- Proof-level requirement: **500 lbf owner-controlled**.
- Complete-system design load: **NOT ESTABLISHED**.
- Complete-system ultimate load/factor: **NOT ESTABLISHED**.
- Required follow-on: structural load-case definition, nonlinear/contact analysis, finished-chain proof procedure and governing ultimate/fatigue criteria.

This is a separate structural verification requirement and does not alter the CO2 mass calculation. It does prevent a structural release claim.
