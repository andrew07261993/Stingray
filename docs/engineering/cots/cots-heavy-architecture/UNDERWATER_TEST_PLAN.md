## Safety boundary

Open-water/pool work is limited to low-energy softgoods and guarded mechanism tests. Hydrostatic depth testing uses a rated chamber and is not proof testing. Live CO2 and regulator/relief fault-flow tests require a qualified facility and approved procedure. This plan provides no improvised high-pressure apparatus instructions.
